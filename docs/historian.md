# PostgreSQL Historian

The `postgres-historian` VM provides the database/historian layer for the virtual industrial automation cell.

## VM Details

| Item               | Value                |
| ------------------ | -------------------- |
| VM name            | `postgres-historian` |
| IP address         | `192.168.1.184`      |
| Database engine    | PostgreSQL           |
| PostgreSQL version | 16.14                |
| Project database   | `industrial_cell`    |
| Project user       | `cell_user`          |

## Database Purpose

The historian stores machine data generated by the automation cell, including:

* Machine telemetry
* Machine state changes
* Production counts
* Alarm records
* Event records

## Initial Tables

| Table               | Purpose                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `machine_telemetry` | Stores live machine values such as state, conveyor status, sensors, counters, and fault state |
| `machine_events`    | Stores machine events such as start, stop, reset, and mode changes                            |
| `machine_alarms`    | Stores alarm records, active status, and acknowledgement state                                |
| `production_counts` | Stores good, rejected, and total part counts                                                  |

## Current Status

PostgreSQL is installed, running, and configured with the `industrial_cell` project database. The initial historian schema has been created and is ready for the gateway integration phase.
